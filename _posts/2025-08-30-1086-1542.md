## 문제 설명

![Image](https://github.com/user-attachments/assets/06a916bd-bc43-4950-aecf-c91e3bc35e69)

문제 링크: [백준 1086번](https://www.acmicpc.net/problem/1086)

박성원은 이 문제를 풀지 못했다.

서로 다른 정수로 이루어진 집합이 있다. 이 집합의 순열을 합치면 큰 정수 하나를 만들 수 있다. 예를 들어, {5221,40,1,58,9}로 5221401589를 만들 수 있다. 합친수가 정수 K로 나누어 떨어지는 순열을 구하는 프로그램을 작성하시오.

하지만, 박성원은 이 문제를 풀지 못했다.

따라서 박성원은 그냥 랜덤하게 순열 하나를 정답이라고 출력하려고 한다. 이 문제에는 정답이 여러 개 있을 수도 있고, 박성원이 우연히 문제의 정답을 맞출 수도 있다.

박성원이 우연히 정답을 맞출 확률을 분수로 출력하는 프로그램을 작성하시오.

---

## 접근 방법

**다이나믹 프로그래밍**\\
**비트마스킹**\\
**비트필드를 이용한 다이나믹 프로그래밍**

## 코드 (C++)

```cpp
#include <iostream>
#include <algorithm>
#include <string>
#include <queue>
#include <numeric>
#define INF 987654321

using namespace std;

int N, K;
string s[15];
long long dp[1 << 15][100];
long long pw[51]; // (10 ^ i) % k
int D[15];

int get_mod(const string &str) {
  int ret = 0;

  for (int i = 0; i < str.length(); i++) {
    ret *= 10;
    ret += str[i] - '0';
    ret %= K;
  }

  return ret;
}

void make_pw() {
  pw[0] = 1 % K;
  for (int i = 1; i <= 50; i++) {
    pw[i] = (pw[i - 1] * 10) % K;
  }
}

long long solve(int visited, int r) {
  if (visited == (1 << N) - 1) {
    if (r == 0) return 1;
    else return 0;
  }

  long long &ret = dp[visited][r];
  if(ret != -1) return ret;     // 이미 계산됨
  ret = 0;  

  for (int i = 0; i < N; i++) {
    if (visited & (1 << i)) continue; // 이미 방문
    int tmp = ((r * pw[s[i].length()]) % K + D[i]) % K;
    ret += solve(visited | (1 << i), tmp);
  }
 
  return ret;
}

int main() {
  ios::sync_with_stdio(false);
  cin.tie(0);                  
  cout.tie(0);
  
  cin >> N;
  
  for (int i = 0; i < N; i++) {
    cin >> s[i];
  }
  
  cin >> K;
  make_pw(); 

  for (int i = 0; i < N; i++) {
    D[i] = get_mod(s[i]);
  }
  
  long long F = 1;
  for (int i = 1; i <= N; i++) {
    F *= i;
  }

  for(int i = 0; i < (1<<N); i++) {
    for(int j = 0; j < K; j++) {
      dp[i][j] = -1;
    }
  }

long long numerator = solve(0, 0);
long long g = gcd(numerator, F);
cout << (numerator / g) << "/" << (F / g) << '\n';
}

```
